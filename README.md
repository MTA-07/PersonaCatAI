# PersonaChat AI

PersonaChat AI, kullanıcıların farklı karakterlere bürünmüş yapay zeka asistanlarıyla sohbet edebileceği Flask tabanlı bir web uygulamasıdır. 

Uygulama içerisinde beş farklı karakter bulunmaktadır: Komik Arkadaş, Ciddi Asistan, Felsefeci, Oyun NPC'si ve Bilim İnsanı. Her karakter, kendi doğasına uygun özel sistem yönergeleri (system prompts) sayesinde benzersiz bir tonda cevap verir.

Proje, backend tarafında Python ve Flask kullanılarak geliştirilmiş olup, yapay zeka yanıtları için OpenRouter üzerinden OpenAI API altyapısını kullanmaktadır.
